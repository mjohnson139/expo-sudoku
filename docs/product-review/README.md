# Current-product review packet

Prepared 2026-08-31 for the product-purpose and redesign workshop.

## PDFs

- `puzzle-box-current-product-map.pdf` — app-level purpose, navigation, persistence and workshop questions.
- `sudoku-current-functionality.pdf` — Sudoku screens, controls, states and design questions.
- `fungiku-current-functionality.pdf` — Fungiku rules, gestures, economy, states and design questions.
- `cube-current-functionality.pdf` — Cube Scramble, solve recording, algorithms, methods and journey.

The matching HTML files are the editable sources. `review.css` contains print styling, and `screenshots/` contains the current web captures used by the PDFs. Screenshots use a 393×852 viewport in Classic theme unless their caption says otherwise.

## Important evidence boundary

The stills document information architecture, visible controls and browser-rendered states. They do **not** claim physical-device verification. Native-only cube finger turns, haptics, software-keyboard avoidance, iOS edge-back, Android hardware-back, cold start and background/resume remain device behaviors.
